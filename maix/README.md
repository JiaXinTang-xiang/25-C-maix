# MaixCam 2 单目视觉测量系统

## 怎么部署到设备

**把下面 5 个文件复制到 TF 卡根目录：**

```
config.py     ← 改这个文件来控制模式
debug.py      ← 日常调试用这个
main.py       ← 比赛时用这个（需接 STM32）
vision.py     ← 视觉算法（不用管）
comm.py       ← 串口通信（不用管）
```

卡插回 MaixCam 2，上电。

---

## 两种用法

### 用法 1：日常调试（推荐新手先试这个）

打开 `config.py`，找到最下面的几行，这样设置：

```python
PROGRAM_MODE = "debug"        # 调试模式
DEBUG_TASK = "a4"             # 先测试 A4 纸能不能检测到
DEBUG_VIEW = "result"         # 显示结果画面
```

然后运行 `debug.py`。

屏幕上会显示摄像头画面，A4 纸检测到会画绿框。

**DEBUG_TASK 有 5 个选项，按顺序试：**

| DEBUG_TASK | 干什么的 | 对应题目 |
|---|---|---|
| `"a4"` | 只检测 A4 纸，不测距 | 先确认摄像头+A4检测正常 |
| `"basic"` | 基础测量：测距 + 正方形/三角/圆形边长 | 基本要求 |
| `"separated"` | 多个分离正方形，找最小的 | 发挥 (1) |
| `"overlap"` | 多个重叠正方形，找最小的 | 发挥 (2) |
| `"rotation"` | A4 纸歪了 30°~60°，也能测 | 发挥 (4) |

**DEBUG_VIEW 有 2 个选项：**

| DEBUG_VIEW | 效果 |
|---|---|
| `"result"` | 显示识别结果（画框、标注） |
| `"binary"` | 显示二值化图像（看阈值效果） |

**跑通了 `a4` 和 `basic` 之后，就说明视觉算法没问题了。**

---

### 用法 2：比赛模式（接上 STM32）

打开 `config.py`，改成：

```python
PROGRAM_MODE = "uart"
```

然后运行 `main.py`。

流程：
1. 上电 → 自动标定（A4 纸放 100cm 处）
2. 标定完 → 屏幕显示预览，等待 STM32 发指令
3. STM32 按按钮 → 发 `0x01` → MaixCam 做基础测量，回传数据
4. STM32 发 `0x02`/`0x03`/`0x04`/`0x05` → 做发挥题，回传数据

---

## 需要调的参数（config.py 里改）

| 参数 | 说明 |
|---|---|
| `UART_RX_PIN` / `UART_TX_PIN` | STM32 接线引脚，对照 MaixCam 2 原理图 |
| `CALIBRATION_DISTANCE_MM` | 标定时 A4 纸距离，默认 1000mm |
| 四个 `COMPENSATION_*` | 经验补偿系数，先用默认值，实测不准再调 |

## 常见问题

**Q: 运行时显示画面但没有检测到 A4 纸？**
→ 确认光照充足，A4 纸的黑边框完整可见。在 `debug.py` 里把 `DEBUG_VIEW` 改成 `"binary"` 看看二值化效果。

**Q: 测出来的距离不准？**
→ 重新标定：把 A4 纸精确放在 100cm 处，跑一次 `main.py`，注意打印的焦距值。也可以手动写死焦距到 config。

**Q: 只想看摄像头画面，不想测任何东西？**
→ `DEBUG_TASK = "a4"` 就行，画面总是有的。
